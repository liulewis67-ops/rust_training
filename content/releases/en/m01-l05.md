## Prerequisites

Finish the preceding lesson and be able to run Cargo commands locally. Examples follow the Rust 1.95.0 / Edition 2024 course baseline.

## Scenario: Lab: repair a failing project

The downloadable starter implements discounted_total_cents using a u8 percentage and i64 amount. The initial type issue hides a subsequent business defect.

## Core concept 1: First repair the type layer

Reproduce E0308 using the specified toolchain. Convert the percentage intentionally rather than assuming different integer types mix implicitly.

## Core concept 2: Then repair the arithmetic

Percentages must be divided by 100. Keep the function signature and every public assertion unchanged.

## Core concept 3: Reproduce the full repair

After cargo check succeeds, run cargo test, compare expected/actual values and finish with fmt, check and test.

## Practice transfer: Turn the initial failure into regression coverage

**Predict:** If ordinary discounts pass, could zero percent or the maximum contract amount still expose a bug?

**Implement:** Keep an untouched starter copy; repair compilation first, then test ordinary and boundary discount values.

**Counterexample and boundaries:** Never delete assertions, alter the public signature or replace expected outputs to force green results.

**Acceptance evidence:** Separate compiler-fix evidence from business-fix evidence; rerun from a fresh checkout.

## Summary

- First repair the type layer: Reproduce E0308 using the specified toolchain.

- Then repair the arithmetic: Percentages must be divided by 100.

- Reproduce the full repair: After cargo check succeeds, run cargo test, compare expected/actual values and finish with fmt, check and test..

## Reference implementation

Read this only after attempting the lab and recording the initial failure.

```rust
pub fn discounted_total_cents(subtotal_cents: i64, discount_percent: u8) -> i64 {
    let percent = i64::from(discount_percent);
    let discount_cents = subtotal_cents * percent / 100;
    subtotal_cents - discount_cents
}
```
