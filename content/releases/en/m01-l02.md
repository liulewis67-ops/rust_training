## Scenario: rustup, Cargo, editions and project layout

You inherit a repository whose Cargo manifest specifies the 2024 edition, while your terminal points at a different compiler or directory.

## Core concept 1: Toolchain responsibilities

rustup installs and selects toolchains; rustc compiles Rust; Cargo manages packages, dependencies, builds and tests.

## Core concept 2: Editions are not compiler versions

An edition controls source language compatibility, not a particular rustc binary. A toolchain selector, rust-toolchain.toml or explicit +version selects the compiler.

## Core concept 3: Trace a minimal package

Cargo.toml declares package and dependencies, src/main.rs is a binary entry, src/lib.rs is a library entry, and Cargo.lock records resolved dependencies.

### Example 1 · text

```text
rustup toolchain install 1.95.0
```

### Example 2 · text

```text
rustup show

cargo +1.95.0 --version
```

### Example 3 · toml

```toml
[package]
name = "hello-rust"
version = "0.1.0"
edition = "2024"
```

### Example 4 · text

```text
hello-rust/
├── Cargo.toml       # package 名称、Edition、依赖声明
├── Cargo.lock       # 已解析的依赖版本，通常由 Cargo 生成
└── src/
    └── main.rs      # binary crate 的常见入口
```

### Example 5 · powershell

```powershell
cargo +1.95.0 new hello-rust --edition 2024
Set-Location hello-rust
Get-Content Cargo.toml
cargo +1.95.0 run
```

### Example 6 · bash

```bash
cargo +1.95.0 new hello-rust --edition 2024
cd hello-rust
cat Cargo.toml
cargo +1.95.0 run
```

## Reason through a counterexample: Reproduce the toolchain

**Problem:** A pilot cannot be reviewed if its toolchain is unknown.

**Principle and deduction:** rustup selects toolchains, Cargo manages package workflows, and the Edition controls language rules. They are separate configuration layers.

**Example and evidence:** Use the example or starter above to check: cargo check works in a clean environment.

**Counterexample:** Recording only cargo --version while omitting rustc and the manifest edition makes another machine's result difficult to reproduce.

**Independent exercise:** Create a tiny library-plus-binary Cargo package, record compiler and manifest settings, and compare cargo check under a deliberately changed toolchain.

**Review:** Explain the roles of Cargo.toml, src/lib.rs, and src/main.rs without treating them as interchangeable.
