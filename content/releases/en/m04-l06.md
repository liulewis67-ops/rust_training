## Reason through a counterexample: Audit ticket handling

**Problem:** Ticket metadata must be read before text is consumed.

**Principle and deduction:** A ticket can be inspected through a borrow before its owned text is handed off; the previous binding cannot be used afterward.

**Example and evidence:** Verify with the existing Rust example or lab: UTF-8 byte lengths and move tests agree.

**Counterexample:** Moving the String before computing its byte length causes a moved-value failure; byte length is also not always character count.

**Independent exercise:** Order inspection before hand-off, then test both ASCII and non-ASCII ticket labels for expected byte counts.

**Review:** Distinguish the end of a temporary read borrow from transfer of ownership.

## Reference implementation

Review after attempting the task; the source code is kept unchanged.

```rust
/// Returns the original UTF-8 byte count and the rendered ticket.
pub fn publish_ticket(source: String) -> (usize, String) {
    let byte_len = source.len();
    let ticket = render_ticket(source);
    (byte_len, ticket)
}

/// Consumes a ticket body and returns its rendered form.
fn render_ticket(body: String) -> String {
    format!("[ticket] {body}")
}
```
