## Reason through a counterexample: Deliver zero-copy lookup

**Problem:** Borrowed returns must point into valid caller-owned input.

**Principle and deduction:** A zero-copy result borrows from caller-owned input; avoiding clones does not make that result independent of the input.

**Example and evidence:** Check the original code or lab: Unicode and short-lived counterexamples behave as required.

**Counterexample:** Returning &str into a temporary local String dangles, while cloning everything into String abandons the zero-copy requirement.

**Independent exercise:** Produce a borrowed query result from caller data, check its content, then attempt to drop the source before using the view.

**Review:** Name the text owner, the borrower, and the period in which the view remains valid.

## Reference implementation

Open only after making an independent attempt.

```rust
pub fn find_token<'text>(text: &'text str, query: &str) -> Option<&'text str> {
    text.split_whitespace().find(|token| *token == query)
}
```
