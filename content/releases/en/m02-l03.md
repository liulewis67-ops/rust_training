### Example 1

```rust
/// Chooses a label from a Boolean comparison.
fn temperature_label(celsius: i32) -> &'static str {
    if celsius >= 20 {
        "warm"
    } else {
        "cool"
    }
}

/// Prints the label selected by the conditional expression.
fn main() {
    println!("{}", temperature_label(18));
}
```

### Example 3

```rust
/// Counts down from the starting value to zero.
fn count_down(mut remaining: u32) -> u32 {
    let mut ticks = 0;
    while remaining > 0 {
        remaining -= 1;
        ticks += 1;
    }
    ticks
}
```

### Example 4

```rust
/// Sums the integers from one through four and returns the sum via break.
fn sum_until_four() -> u32 {
    let mut next = 1;
    let mut total = 0;
    loop {
        if next > 4 {
            break total;
        }
        total += next;
        next += 1;
    }
}
```

### Example 5

```rust
/// Sums a bounded inclusive integer range.
fn sum_one_to(limit: u32) -> u32 {
    let mut total = 0;
    for value in 1..=limit {
        total += value;
    }
    total
}

/// Prints a short inclusive sequence.
fn main() {
    for value in 1..=3 {
        println!("{value}");
    }
}
```

## Java / Go comparison

Unlike many Java/Go conditional statements, Rust's if block can also yield a value. Explicit bounds are still necessary in every language.

## Practice transfer: Prove an inclusive range

**Predict:** Do 0..n and 0..=n iterate the same values when n is 1?

**Implement:** Write for- and while-based totals with documented loop bounds and exit conditions.

**Counterexample and boundaries:** Test n=0, n=1 and a general case without confusing overflow with off-by-one errors.

**Acceptance evidence:** List iteration counts and totals; include an assertion that catches the wrong upper bound.
