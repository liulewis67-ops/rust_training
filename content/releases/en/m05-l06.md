## A correct UTF-8 split does not make later mutation safe

A parser borrows two slices from a string and then wants to modify the original. The delimiter may define a valid UTF-8 boundary, yet a later use of either borrowed slice still conflicts with mutation.

Finish the work that needs those views before modifying the source, or create an explicitly owned copy if data must survive the change. Text-boundary correctness and borrow validity are separate contracts; a robust interface must satisfy both.

## Reference implementation

Open only after making an independent attempt.

```rust
pub fn split_label<'text>(
    text: &'text str,
    separator: &str,
) -> Option<(&'text str, &'text str)> {
    if separator.is_empty() {
        return None;
    }

    let start = text.find(separator)?;
    let end = start.checked_add(separator.len())?;
    Some((text.get(..start)?, text.get(end..)?))
}

fn main() {
    let mut label = String::from("部署：完成");
    let (kind, value) = split_label(&label, "：").unwrap();
    println!("parts: {kind} / {value}");
    label.push('!');
    println!("updated: {label}");
}
```
