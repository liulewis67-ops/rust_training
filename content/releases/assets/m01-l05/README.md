# M01-L05：修复折扣金额工具

本项目使用 Rust 1.95.0 与 Edition 2024。函数 `discounted_total_cents` 接收 `0..=1_000_000` 的整数分值与 `0..=100` 的折扣百分比；折扣分值向下取整，返回扣除折扣后的总分值。

起始代码包含两个独立问题：先是阻止编译的类型错误；修好后，公开测试会暴露折扣计算错误。请保留失败诊断、每次修改和复验结果。

在本目录运行：

```text
rustc +1.95.0 --version
cargo +1.95.0 check
cargo +1.95.0 test
```

测试文件是公开的学习辅助材料，可以被修改；单纯删除或改弱断言无法证明实现满足契约。完成修复后，对照课程页的参考实现，并用零折扣、10% 折扣、100% 折扣和非整分折扣输入自行检查。

需要重做时，先把个人修改另存到别处，再从原始 ZIP 解压到**新的空目录**。该操作不需要网站账号或在线运行环境。
