# M01-L03：区分编译、测试与运行失败

三个子目录是独立的 Cargo 项目。先安装 Rust 1.95.0：`rustup toolchain install 1.95.0`。解压后分别进入项目目录，运行下表中的起始命令，记录失败阶段，再按参考修复重跑。Windows、Linux 与 macOS 都可使用这些 Cargo 命令。

| 子目录 | 起始命令 | 预期失败 | 参考修复与复验 |
| --- | --- | --- | --- |
| `compile-fail` | `cargo +1.95.0 check` | 类型不匹配，E0308 | 把字符串字面量改为 `3_u32`，再运行 `cargo +1.95.0 run`，预期输出 `3`。 |
| `test-fail` | `cargo +1.95.0 test` | 一项断言失败 | 把错误期望 `5` 改为 `4`，再运行 `cargo +1.95.0 test`，应有 1 项测试通过。 |
| `runtime-fail` | `cargo +1.95.0 run` | 构建成功，程序解析输入时 panic | 将输入改为 `42`，再运行 `cargo +1.95.0 run`，预期输出 `42`。 |

这三条初始失败与参考修复已在 Windows 的 Rust 1.95.0 上复现。终端诊断的完整措辞可能随平台变化；判断依据是失败阶段、E0308 或断言／panic 的性质，以及修复后命令的结果。
