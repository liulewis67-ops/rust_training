# M01-L06：公开参考项目

本目录是综合自测的一个参考实现，使用 Rust 1.95.0 和 Edition 2024。它公开展示 `Cargo.toml`、库函数、程序入口和行为测试；学习者可以先独立完成，再对照这里检查项目结构和边界行为。

在本目录运行：

```text
rustup toolchain install 1.95.0
cargo +1.95.0 fmt -- --check
cargo +1.95.0 check --all-targets
cargo +1.95.0 test
cargo +1.95.0 run
```

测试应覆盖 `0`、`7`、`1000`、`1234` 分；程序输出应为 `12.34`。可以再添加 `82`、`4007`、`1_000_000` 分作为公开自查输入。参考项目只是学习材料，本地通过不构成网站认证成绩。
