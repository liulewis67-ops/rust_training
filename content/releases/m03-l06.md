## 契约

- `None` 返回 `"not found"`。
- `Queued` 返回 `"claim"`；`Claimed` 返回 `"deliver"`。
- `Delivered { attempts }` 在 `attempts < 2` 时返回 `"retry"`，否则返回 `"archive"`。

## 参考实现

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AlertStatus {
    Queued,
    Claimed,
    Delivered { attempts: u8 },
    Cancelled { by_user: bool },
}

pub fn next_action(status: Option<AlertStatus>) -> &'static str {
    match status {
        None => "not found",
        Some(AlertStatus::Queued) => "claim",
        Some(AlertStatus::Claimed) => "deliver",
        Some(AlertStatus::Delivered { attempts }) => {
            if attempts < 2 { "retry" } else { "archive" }
        }
        Some(AlertStatus::Cancelled { by_user: true }) => "close",
        Some(AlertStatus::Cancelled { by_user: false }) => "review",
    }
}
```

没有通配分支，因此新增 `AlertStatus` 变体会触发穷尽性诊断。
