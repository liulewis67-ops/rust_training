## 分层提示

1. 先检查 `strip_prefix('#')` 是否成功，成功时已拿到原输入的子切片。
2. 返回原切片时使用 `Cow::Borrowed`，不要调用 `to_string`。
3. 需要添加井号时用 `format!` 构造结果并返回 `Cow::Owned`。
4. 用变体匹配与指针范围断言共同验证分支和数据来源。

## 参考实现

```rust
use std::borrow::Cow;

pub fn normalize_topic<'input>(topic: &'input str) -> Cow<'input, str> {
    if let Some(suffix) = topic.strip_prefix('#') {
        Cow::Borrowed(suffix)
    } else {
        Cow::Owned(format!("#{topic}"))
    }
}

#[test]
fn normalize_topic_contract() {
    use std::borrow::Cow;

    assert!(matches!(normalize_topic("rust"), Cow::Owned(value) if value == "#rust"));
    let raw = String::from("#你好");
    let result = normalize_topic(&raw);
    assert!(matches!(&result, Cow::Borrowed(value) if *value == "你好"));
    let Cow::Borrowed(value) = &result else { panic!("expected a borrowed slice") };
    let start = raw.as_ptr() as usize;
    let end = start + raw.len();
    let part_start = value.as_ptr() as usize;
    assert!((start..=end).contains(&part_start));
    assert!(part_start + value.len() <= end);
    assert!(matches!(normalize_topic(""), Cow::Owned(value) if value == "#"));
    assert!(matches!(normalize_topic("##rust"), Cow::Borrowed("#rust")));
}
```

固定内置文本适合 `&'static str`；同步借用适合 `&'a str` 或借用视图；需要跨过输入作用域保存时用 `String` 或拥有型结构体。这里的 `Cow` 在已有前缀时借用原输入，在需补前缀时拥有新建文本。`into_owned` 在 Borrowed 分支复制成 owned 值，在 Owned 分支直接取出已有的 `String`。
