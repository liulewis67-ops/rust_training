# M01-L06：综合自测——从空目录交付可测试程序

本节把 M01 的工具链、项目结构、编译、测试和输出检查串起来。建议先独立完成，再展开公开参考项目；查看答案不会影响后续课程访问，本站也不颁发独立能力成绩。

## 学习目标与环境

从空目录创建 Cargo 应用，拆分库函数和程序入口，添加能检查行为的测试，并保存格式、构建、测试与运行的结果。先完成 M01-L01–L05；使用 Rust 1.95.0 与 Edition 2024，在本地电脑操作。

## 题面

在空目录中创建名为 `amount-formatter` 的二进制 package。实现公开函数：

```rust
pub fn format_cents(amount_cents: u32) -> String
```

函数把非负整数分值格式化为不带货币符号、没有千位分隔符的十进制金额，小数点后始终两位：`7` → `"0.07"`，`1234` → `"12.34"`，`1000` → `"10.00"`。在 `main` 中调用函数并输出 `12.34`。项目至少包含 `Cargo.toml`、`src/lib.rs`、`src/main.rs` 和两项有行为断言的测试；测试分别覆盖小于一元和整元或零。

## 本地操作与公开自查

先运行 `rustup toolchain install 1.95.0`，在空目录旁运行 `cargo +1.95.0 new amount-formatter --edition 2024`，进入新项目并按题面添加文件。完成后在项目根目录运行：

```text
cargo +1.95.0 fmt -- --check
cargo +1.95.0 check --all-targets
cargo +1.95.0 test
cargo +1.95.0 run
```

检查测试运行结果中的通过数量确实大于零，程序标准输出只有 `12.34`。再用 `0`、`82`、`4007`、`1_000_000` 分自行检查 `0.00`、`0.82`、`40.07`、`10000.00`。本地通过说明这些公开输入和测试覆盖的行为符合契约；它不能代替未检查场景的证明。

## 分层提示

1. 把整数分值分别除以 100 和取余 100，得到元和余下的分。
2. 余下的分在 0–9 时仍要显示两位，可使用格式化宽度与前导零。
3. 库函数放在 `src/lib.rs`；`main` 从本 package 导入它并打印结果。
4. 测试必须调用函数并断言结果；只检查“没有 panic”或写 `assert!(true)` 不足以保护格式契约。

## 参考实现

下载[公开参考项目 ZIP](./m01-l06-reference.zip)。项目包含完整清单、源码和 4 项行为测试，已在 Windows 的 Rust 1.95.0 上通过格式检查、全目标编译、测试和运行，程序输出 `12.34`。

核心函数如下；参考项目还展示了 `main` 和测试如何组织：

```rust
pub fn format_cents(amount_cents: u32) -> String {
    format!("{}.{:02}", amount_cents / 100, amount_cents % 100)
}
```
