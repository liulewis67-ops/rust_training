## 定义与调用函数

函数把一段有名字的行为变成可重复调用的边界。名称使用 `snake_case`。参数在签名中声明名字和类型，返回类型写在 `->` 后：

```rust
/// Multiplies a unit price by a quantity under the caller's bounds.
fn line_total(unit_price_cents: u32, quantity: u32) -> u32 {
    unit_price_cents * quantity
}

/// Prints the result of calling the calculation function.
fn main() {
    let amount = line_total(250, 3);
    println!("{amount}");
}
```

`line_total` 的调用点必须给出两个 `u32` 参数；它把乘法结果返回给调用方。题面或业务契约应限制输入范围，使乘法结果可表示。参数和返回类型属于函数接口，编译器会检查调用是否符合它们。

函数可以先被调用、后定义。是否写在 `main` 前面不改变可见范围；把一段计算提取成函数时，应让名字、输入和结果都表达清楚。

## 语句做事，表达式给出值

Rust 的块由若干语句组成，末尾可以有一个表达式。赋值绑定的 `let` 是语句，不会产生可供外层继续使用的值；算术、函数调用等通常是表达式：

```rust
/// Returns a calculation produced by a block expression.
fn adjusted_count() -> i32 {
    let imported = 12;
    let rejected = 2;
    imported - rejected
}
```

函数体最后的 `imported - rejected` 没有分号，是块的尾表达式；其值 `10` 成为函数返回值。若写成 `imported - rejected;`，它变成语句，函数体的值是 `()`（unit），与声明的 `i32` 返回类型不符，编译器会报类型不匹配。

同理，不能把声明语句当成值赋给另一个名字：

```rust
/// This intentionally fails because a let statement has no value.
fn invalid_assignment() {
    let _result = (let _source = 7);
}
```

这段代码故意展示错误写法，不能作为可运行示例。`let _source = 7;` 完成绑定后不返回值，所以外层没有可赋给 `_result` 的表达式。此类问题应从语法和类型诊断定位，而不是给函数随意改返回类型。

## 显式 `return` 与尾表达式

普通路径通常让最后一个表达式作为结果；需要提前结束当前函数时，可以用 `return`：

```rust
/// Returns the unchanged input through the function's tail expression.
fn identity(value: i32) -> i32 {
    value
}

/// Returns the input through an explicit return statement.
fn identity_explicit(value: i32) -> i32 {
    return value;
}
```

`return` 会立刻结束当前函数调用；省略 `return` 时，尾表达式仍要与箭头后声明的类型一致。本节只比较返回写法，不展开条件分支；边界建模和错误返回类型会在后续课程细化。

## 阅读和修复返回错误

```rust
/// This intentionally fails because the semicolon discards the i32 value.
fn plus_one(value: i32) -> i32 {
    value + 1;
}
```

这个函数声明返回 `i32`，但尾部语句没有返回值，因此实际块值为 `()`。删掉最后表达式后的分号即可让其值作为函数结果；也可以显式 `return value + 1;`。选择尾表达式通常更简洁。不要只删箭头类型来压掉诊断，先核对调用方需要什么结果。
