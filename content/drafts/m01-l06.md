# M01-L06：检查——从空目录交付可测试程序

## 目标与规则

从空目录开始，按新需求建立一个最小 Cargo 项目，加入一个有明确输入输出契约的函数和测试，并通过构建和行为检查。本检查观察你能否独立组织工具链反馈循环，不要求背诵前几节的命令输出。

可以查看公开 Rust/Cargo 文档；不能查看本题参考方案。本地运行结果仅供自查。只有未查看答案且通过题面以外行为检查的提交，才能作为独立能力证据。

## 检查任务

### 题面

在空目录中创建名为 `amount-formatter` 的 Cargo binary package，使用 Edition 2024。实现并公开函数：

```rust
pub fn format_cents(amount_cents: u32) -> String
```

函数把非负整数分值格式化为不带货币符号和千位分隔符的十进制金额：小数点前为整元，小数点后必须有两位数字。例：`7` 得到 `"0.07"`，`1234` 得到 `"12.34"`，`1000` 得到 `"10.00"`。在 `main` 中调用函数并输出 `12.34`。添加至少两项有行为断言的测试，其中一项覆盖小于一元的输入，另一项覆盖整元或零；测试不能只确认程序未崩溃。

需从空目录完成 `Cargo.toml`、`src/lib.rs`、`src/main.rs` 和测试；交付前检查格式、构建、测试和程序输出。公开练习会反馈 Cargo 项目结构、构建、测试发现和本地输出。不能将本地通过信息当作正式检查结果。
