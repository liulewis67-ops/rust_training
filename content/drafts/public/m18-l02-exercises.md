# M18-L02：查询与映射短练习

## 预测：查询结果边界

对不存在 ID、唯一 ID 与 prefix 命中多行分别选择合适的 fetch API，并说明数据库故障与“没有匹配行”的区别。

提示：`fetch_optional` 表示 0/1；列表查询要保留所有匹配行。

## 修复：移除用户输入 SQL 拼接

修复被 `AssertSqlSafe` 包裹的 ID 字符串拼接注入问题；查询结果映射为 Label，缺失时返回 None。

提示：SQL 字符串只保留固定结构，再把 ID 交给 `.bind(...)`。安全断言 wrapper 不能代替参数绑定。

## 实现：按 ID 查询和 prefix 列表

实现参数化的按 ID 查询与 prefix 列表接口，并通过 SQLite 契约覆盖缺失、单行、多行和注入哨兵。

提示：LIKE 前缀可以先作为普通 String 参数构造，再绑定到固定 SQL；测试使用新建的单连接内存数据库。
