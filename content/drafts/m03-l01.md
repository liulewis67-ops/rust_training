# M03-L01：结构体、字段与方法

## 学完后

- 用命名字段建模一个相关数据组合，并创建字段值符合类型的实例。
- 通过点号读取字段；只有可变实例才能直接修改字段。
- 在 `impl` 中定义方法，区分只读的 `&self` 和允许修改的 `&mut self` 接收者。
- 根据编译诊断修正字段类型或方法参数调用错误。

## 先修

完成 M02-L06，能按函数签名提供参数，理解变量的可变绑定和借用写法，并能读取编译器诊断。本节只使用 `u16`/`u32` 数值字段，不把引用存进结构体，也不展开生命周期。

## 命名字段说明数据含义

元组用位置表示含义；结构体给每个字段一个名字。当几个值共同描述一件事，且字段位置容易记错时，用结构体表达它们之间的关系：

```rust
/// Represents a rectangle with bounded dimensions.
pub struct Rectangle {
    pub width: u16,
    pub height: u16,
}

/// Creates and reads a rectangle value.
fn main() {
    let rectangle = Rectangle {
        width: 8,
        height: 5,
    };
    println!("{} by {}", rectangle.width, rectangle.height);
}
```

定义列出名称和类型；创建实例时要为每个字段提供值，字段书写顺序可以不同。`pub` 让本例的类型和字段可从其他模块访问；可见性策略会在后续单元集中讨论。字段类型不匹配会被编译器拒绝，例如将字符串切片赋给 `width: u16`。

字段访问使用点号。若要直接修改字段，实例绑定必须是 `mut`：

```rust
/// Changes a rectangle field through a mutable instance.
fn main() {
    let mut rectangle = Rectangle {
        width: 8,
        height: 5,
    };
    rectangle.width = 10;
    println!("{}", rectangle.width);
}
```

`mut` 标在整个绑定上，不是结构体定义的单个字段上。不可变实例仍可读取字段；对它写入会产生可变性编译错误。

## 用方法把行为放在相关数据旁

`impl Rectangle` 块把方法关联到类型。接收者参数指出方法如何使用调用实例：

```rust
/// Represents a rectangle with bounded dimensions.
pub struct Rectangle {
    pub width: u16,
    pub height: u16,
}

/// Defines calculations and updates for rectangles.
impl Rectangle {
    /// Returns the area of the rectangle.
    pub fn area(&self) -> u32 {
        u32::from(self.width) * u32::from(self.height)
    }

    /// Replaces the width while leaving the height unchanged.
    pub fn set_width(&mut self, width: u16) {
        self.width = width;
    }

    /// Returns whether this rectangle contains the other rectangle.
    pub fn can_fit(&self, other: &Rectangle) -> bool {
        self.width >= other.width && self.height >= other.height
    }
}

/// Demonstrates read-only and mutable method calls.
fn main() {
    let mut outer = Rectangle {
        width: 10,
        height: 6,
    };
    let inner = Rectangle {
        width: 4,
        height: 3,
    };
    println!("{} {}", outer.area(), outer.can_fit(&inner));
    outer.set_width(3);
    println!("{}", outer.area());
}
```

`&self` 是只读借用接收者；方法读取实例，不取得它的所有权，也不允许通过这个接收者修改字段。`&mut self` 是可变借用接收者，需要可变实例，并在调用期间独占地借用它。`set_width` 调用后，`outer` 仍是原来的实例，只是宽度更新为新值。方法签名中除接收者外的其他参数仍须按类型和数量提供；调用 `set_width()` 时漏掉宽度参数会编译失败。

## 选择字段、函数或方法

只需要表示几项相关数据时，定义结构体并按契约构造实例；一个操作若主要依赖实例已有字段，把它写成方法可让调用点成为 `rectangle.area()`。不依赖某个具体实例的计算仍可写成普通函数。选择 `&self`、`&mut self` 或其他接收方式时，先说明操作是否修改实例以及调用方是否还要继续使用它；本课所有方法都借用实例，不消费整个结构体。

面积实现先把 `u16` 字段转成 `u32` 再相乘。两个 `u16` 最大值的乘积可由 `u32` 表示；若日后扩大字段类型，应重新验证结果范围，不能依赖当前示例数据。

## 检查方法错误

- 对字段错误，比较结构体定义中的类型与实例提供的值；不要删除字段或换成不相关的类型来消除诊断。
- 对方法错误，核对调用接收者类型、除接收者以外的参数个数和各参数类型。
- 对变更行为，检查实例绑定是否 `mut`，以及方法接收者是否写成 `&mut self`。
- 先用 `cargo check` 定位类型/借用错误；成功编译后再用测试确认计算和修改的结果。
