# M01–M08 已发布课程内容复核（48 节）

## 本次范围与原则

- 范围为 M01-L01 至 M08-L06，共 8 模块 × 6 节 = **48 节**。当前公开目录另外包含 M09 的 6 节，本次未修改。
- 对已有教学内容实行**增量增强**：保留经过公开项目测试的源代码、练习、文件与文献链接；不为追求统一模板重写全部教程。
- 每节新增**一个独立的工程迁移挑战**，由问题预测、具体改造、反例或边界以及验收证据组成。实验和模块综合自测同样覆盖。
- 新挑战属于阅读器的实践分区，不应计入“知识点 01/02”编号。

## 验收方式和边界

- 在 CI 中执行 `src/content/course-transfer-structure.test.ts`，对 48 篇 Markdown 逐篇检查：ID、来源、迁移挑战完整性、正确的实践分区以及代码围栏配对。
- 继续依靠项目现有的 Prettier、ESLint、TypeScript、Vitest、Cargo 实验契约、公开课清单与生产构建完成集成检查。
- 这些检查**不能代替 48 个迁移任务的人工作答或逐份 Rust 新代码运行**。新增挑战是明确的练习说明和验收要求，不代表所有新变式已由独立自动评测覆盖。
- 以后若扩展课程自动评测，优先为实验课提供可下载的 starter/reference 与可运行测试，避免写出尚未存在的在线能力。
