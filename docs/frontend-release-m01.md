# FE04：M01 首批公开课程核验

日期：2026-10-17。范围：M01-L01–L06 六节 Markdown、L01–L04 的公开练习、L03/L04/L05 的样例或起始项目 ZIP、L06 的参考项目 ZIP，以及 `borrowed-text` 课包补充的公开参考测试。

发布目录中的文字、样例和 ZIP 从既有草稿逐项整理；原 `content/drafts/` 与教师／私有评测材料未纳入公开构建。参考答案与提示在页面中主动展开，学习者可按题面自行练习，没有平台评分或受控测试的承诺。每节正文都列出核对用的官方资料，课程情境与示例代码为原创。

| 课节 | 本地核验（Rust 1.95.0，Windows） |

核验使用从 ZIP 解压出的独立目录或新建 Cargo 项目，没有把临时修复写回起始 ZIP。`pnpm content:validate-public` 检查六节标题、来源段落、练习文件与 ZIP 链接；`pnpm check:frontend` 检查目录发布边界、提示和答案折叠、导航及前端构建。Linux/macOS 上的 Rust 命令及真实 Pages 下载体验仍需线上或其他系统复核；M02–M03 尚未达到发布条件。
