- 环境：Windows NT 10.0.26300.0；Rust/Cargo 1.95.0；Node.js 22.19.0；pnpm 11.1.3

## 迁移、配置和回退

- `0004_learning_provenance.sql` 为现有自评表增加来源列，默认既有记录为 `learner_reported`；`0005_learning_event_activity.sql` 为既有事件增加活动标记，默认旧事件仍计入学习日。启动时仅在 SQLite schema 缺少对应列时运行增量迁移。
- 使用已有 `DATABASE_URL` SQLite 文件，无新增秘密或服务配置。迁移只添加列，不删除或重写原学习数据；旧 localStorage v1 来源键也不会被导入流程修改或清理。
- 回退应用版本时保留新增列、事件标记及 v1 来源数据，不执行 `DROP`；回退前备份 SQLite 文件，并保留能兼容新列的版本或恢复数据库副本。

## 限制

- v1 课程映射来自 `content/legacy-course-map.json`；未知课程不会进入新结构化记录，只能从原始 v1 备份中查看。
- 真实 OIDC issuer/client 仍未配置；跨账户云端路径由受控测试 Session 和 SQLite 集成测试覆盖，真实登录验收继续由 I02-F05 跟踪。
